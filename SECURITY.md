# Security policy

## Supported versions

Security fixes are applied to the current default branch and, after the first stable release, to the
latest supported release line. Pre-release snapshots and older deployments may not receive
backports.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's **Report a vulnerability** option for this repository to open a private security
advisory. Include:

- the affected revision or deployment;
- a concise description of the impact;
- reproducible steps or a minimal proof of concept;
- relevant browser, operating-system, and dependency versions;
- any suggested mitigation, if known.

We aim to acknowledge reports within five business days. The report will be assessed privately
before a remediation and disclosure plan is agreed.

## Scope

Useful reports include vulnerabilities in the application, dependency chain, build workflow,
deployment configuration, or repository automation. Reports that only describe unsupported browsers,
expected local-storage modification, or unverified automated-scanner output without an exploitable
impact may be closed without a security release.
